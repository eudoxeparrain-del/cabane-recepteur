# Cabane — récepteur Cast

La page que la télé du salon charge quand l'app **Cabane** lui envoie
l'écran vinyle (Google Cast, App ID `7C3C3269`).

Elle ne contient que du dessin (HTML/CSS/JS) : les données — pochette,
titre, face en cours — arrivent au moment du cast, par le canal
`urn:x-cast:com.eudoxe.cabane`. Rien de personnel n'est hébergé ici.

Source de vérité : le repo local `app-salon` (`recepteur-cast/index.html`).
